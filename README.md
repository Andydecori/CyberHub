# CyberHub_ | Plataforma de Ciberseguridad Defensiva 

CyberHub es un proyecto académico de desarrollo web centrado en la educación sobre vulnerabilidades de sistemas, criptografía clásica y defensa de infraestructuras. 

Este proyecto fue desarrollado como evaluación final práctica, demostrando la integración de tecnologías Front-End puras, sin el uso de frameworks externos, cumpliendo con estrictos estándares de semántica web, diseño UI/UX y separación de responsabilidades (código limpio).

##  Características Principales

* **Simulador de Cifrado César:** Un módulo interactivo desarrollado en JavaScript que permite la manipulación del DOM en tiempo real para cifrar y descifrar texto mediante lógica matemática modular.
* **Catálogo de Amenazas:** Documentación técnica sobre vectores de ataque comunes (Sniffing, SQL Injection, Escaneo de Puertos), documentados con capturas de auditorías reales en entornos virtualizados (Kali Linux, Ubuntu, Wireshark).
* **Glosario Técnico:** Estructuración de datos mediante tablas semánticas para definir terminología clave en el ámbito de la ciberseguridad.
* **Diseño UI/UX (Dark Mode):** Interfaz unificada, responsiva y estéticamente orientada a entornos de terminales de seguridad, construida íntegramente con CSS3.

##  Tecnologías Utilizadas

* **HTML5:** Estructura semántica validada (`<header>`, `<main>`, `<section>`, `<article>`, `<nav>`).
* **CSS3:** Flexbox, variables globales, transiciones y diseño responsivo adaptativo.
* **JavaScript (Vanilla JS):** Escucha de eventos, iteración de arrays/strings y algoritmos de criptografía.
