Glosario Técnico de Seguridad

Material de apoyo para estandarizar la terminología técnica relacionada con vulnerabilidades del sistema, tácticas de ataque y medidas de mitigación defensiva.

Términos Frecuentes

Término Definición Técnica Categoría
Malware Software malicioso diseñado específicamente para infiltrarse, dañar o comprometer la operatividad de un sistema informático sin el consentimiento del usuario. Amenaza
Phishing Técnica de engaño que busca manipular al usuario para que revele información confidencial (credenciales, datos financieros) suplantando una identidad legítima. Amenaza
Ransomware Tipo de malware que emplea algoritmos para cifrar los archivos críticos de la víctima, exigiendo un rescate económico a cambio de la clave de descifrado. Amenaza
Ingeniería Social Manipulación psicológica de las personas para inducirlas a eludir protocolos de seguridad, realizar acciones específicas o revelar información confidencial. Amenaza
Botnet Red de equipos informáticos infectados (zombis) controlados de forma remota por un atacante para ejecutar actividades maliciosas coordinadas, como ataques DDoS. Amenaza
Cifrado (Encriptación) Proceso criptográfico que altera los datos mediante algoritmos matemáticos, volviéndolos ininteligibles para cualquier persona que no posea la clave de descifrado. Defensa
Autenticación Proceso de verificación rigurosa de la identidad de un usuario, dispositivo o sistema antes de autorizar su acceso a recursos protegidos. Defensa
Firewall (Cortafuegos) Sistema de seguridad de red que monitorea y controla el tráfico entrante y saliente basándose en reglas lógicas predeterminadas para bloquear accesos no autorizados. Defensa
Vulnerabilidad Debilidad, fallo o error de diseño en un sistema, aplicación o arquitectura de red que puede ser explotado por una amenaza para comprometer la seguridad. Defensa
Parche (Patch) Actualización de código liberada por el desarrollador de un software, diseñada para corregir vulnerabilidades de seguridad o solucionar errores técnicos (bugs). Defensa
